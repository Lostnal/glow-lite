# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-16

### Added

- Native Live Activity / Dynamic Island control for the glowing Apple logo on PROLED XDR MacBook Pros.
- Expanded island with a single Apple toggle; compact island shows the current state.
- Dismissal 3 seconds after the last tap, and 15 seconds after the activity is shown with no interaction.
- Dock and menu-bar-only residence modes.
- Space black / silver enclosure preview, or follow the current Mac.
- Optional passwordless helper for `CoreBrightness` `LEBacklightMode`, with per-click authorization fallback.
- Developer ID signing, notarization, and DMG release workflow.
